## What is WaPulse Pro?

WaPulse Pro is a powerful Windows desktop application built for businesses and marketers who want to run professional WhatsApp marketing campaigns at scale. Featuring a clean Material Design interface, it lets you send bulk messages to contacts and groups, automate replies, schedule campaigns, and analyze results — all from one easy-to-use tool.

Built on .NET 8 with WPF, WaPulse Pro runs natively on Windows 10/11 and connects to WhatsApp via Playwright-based browser automation — no API keys or third-party subscriptions required.

---

## Key Features

- **Contact Sender** — Send bulk WhatsApp messages to individual contacts from CSV/Excel lists. Supports text, images, documents, and rich media. Anti-spam delay controls and personalization tokens keep your messages natural.

- **Group Sender** — Target WhatsApp group chats directly. Send announcements, promotions, or updates to all your groups in one go, with per-group customization support.

- **Auto Reply Bot** — Set up keyword-triggered automatic replies. When a contact messages you with a specific keyword, WaPulse Pro instantly responds with your configured message — available 24/7 without manual intervention.

- **Account Warmup** — Safely ramp up a new WhatsApp number with automated warmup sequences. Gradually increase messaging activity to build account trust and reduce spam flagging.

- **Campaign Scheduler** — Schedule campaigns to send at the optimal time. Plan your entire week's outreach in advance with date/time-based scheduling and recurring campaign support.

- **Analytics Dashboard** — Track delivery rates, response rates, and campaign performance over time. Visual charts and exportable reports help you optimize future campaigns.

- **Multi-Account Manager** — Manage multiple WhatsApp accounts from a single interface. Switch between business numbers, personal lines, or client accounts instantly.

- **Tools Suite** — Built-in utilities including contact list deduplication, number validator, group extractor, and message template manager.
